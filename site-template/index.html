remoteplayer APT repository

Debian packages for Raspberry Pi OS (bookworm, trixie; arm64, armhf) and Debian/Ubuntu on amd64.

Add the repository

sudo curl -fsSLo /usr/share/keyrings/remoteplayer-archive-keyring.gpg \
    https://endownment.github.io/endownment-remoteplayer-apt/remoteplayer-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/remoteplayer.sources \
    https://endownment.github.io/endownment-remoteplayer-apt/remoteplayer.sources
sudo apt update

Install

sudo apt install remoteplayer-restservice remoteplayer-mpvwatcher

Then follow the "Installation" section of the remoteplayer-restservice README (set the API token, enable the units). Later versions arrive with sudo apt upgrade.

Packages

  • remoteplayer-restservice: the REST API and the mpv unit
  • remoteplayer-mpvwatcher: follows the playback state for restoring it

Signing key: remoteplayer-archive-keyring.asc. Index: dists/stable/Release.
